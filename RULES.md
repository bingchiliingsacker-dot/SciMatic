## 1. If committing a change, make sure there are no bugs.
- Bugs are banned for obvious reasons.

## 2. Only use lightweight libraries
- Only create files that have either lightweight/python-standard libraries like math, random, and re. Or none at all.
- Heavyweight libraries like NumPy and SciPy are banned inside SciMatics **core** code.

#### Just follow these 2 rules and no conflict will happen.
